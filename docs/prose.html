Prose

Read the draft. Mark the bit that needs work.

A browser window for writing with an agent. Select a passage and leave a comment: “What does this mean?” “Too long.” “Keep the point, lose the throat-clearing.”

With an agent connected, the answer appears beside the draft. Ask for an edit and the Markdown file changes too.

Less copy-paste

You’re reading a letter. The second paragraph sounds like somebody trying to win an argument on LinkedIn. Highlight it, ask for something less grand, and read the change where it belongs—not in another chat bubble.

You can type directly in the page, too. Comments and replies stay with the draft. If another editor changes the file while you’re writing, Prose asks you to resolve the conflict rather than quietly replacing your work.

Getting started

Prose is part of xo, but you don’t need the rest of xo to use it.

You’ll need Deno 2.9.6 and, for agent replies, a compatible Claude Code or Codex session. The agent guide covers the download and launch commands. First use needs an internet connection for dependencies; the browser editor is already bundled. No Node.js or Helix needed for the plain editor.

Windows + Claude: the tested route needs --allow-windows-claude-all-access. It disables Deno’s permission sandbox, giving the process broad access to files, programs and the network. Use it only if you’re comfortable trusting Prose with that access. The default launcher does not enable it.

Mac: the editor and browser checks passed. The connection to a real agent hasn’t been verified. Try a throwaway draft before relying on comments reaching your agent.

Text read by a cloud agent goes to its provider. Keep the local session URL private and stop the server when you’re done.
