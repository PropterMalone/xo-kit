Direct Delete — RC3

Direct Delete is available in the RC3 source preview, not earlier packages. Select a passage and choose Delete to remove it directly from your Markdown file, with no model or connected agent. Undo with Ctrl+Z in the plain editor.

Prose refuses the deletion if the selection is ambiguous or stale, or the plain editor has unsaved changes. Your current file is authoritative: if you change or undo the deletion, do not ask the agent to reapply it.

Getting started

Prose is part of xo, but you don’t need the rest of xo to use it.

You’ll need Deno 2.9.6 and, for agent replies, a compatible Claude Code or Codex session. The agent guide covers the download and launch commands.

Windows + Claude: the tested route needs --allow-windows-claude-all-access. It disables Deno’s permission sandbox, giving the process broad access to files, programs and the network. Use it only if you’re comfortable trusting Prose with that access. The default launcher does not enable it.

Mac: prior RC1 editor and browser checks passed; the changed RC3 runtime has not been run natively on macOS.

Text read by a cloud agent goes to its provider. Keep the local session URL private and stop the server when you’re done.
