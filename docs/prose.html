Prose, by David Crespo

Read a draft in your browser. Select a passage, ask a question or request a change. With a working connection, XO answers or revises the Markdown file, and you see the result on the page.

Prose is optional. Writing in chat still works.

With xo

You choose the draft and what you want help with. XO carries the setup and keeps track of the work. A question should get an answer, not an unwanted rewrite. A requested change should stay within what you asked for.

The Markdown file stays yours. Liking the wording does not confirm its facts, approve broader reuse or send it anywhere.

With a cloud assistant, the text XO reads goes to its model provider. A local browser does not change that. You choose what to share and save.

Availability

Prose is a core XO module. Installing and using it are optional.

Limited prerelease: release 0.1.0-rc.1, source ZIP and SHA256 checksum. Verify public availability and the pinned checksum before setup. Mac real-agent handling and interrupted-agent recovery are unverified. The separate Prose attachment is not GitHub's automatic XO source download.

Install Deno 2.9.6 separately. The plain editor needs no Node.js, npm command, Python or Helix. The browser bundle is included, but server dependencies download on first use. This is not an offline distribution. XO can carry the permitted setup and verify a fictional draft before using yours; selecting this guide installs nothing.

A cached native Windows x64 route with Claude 2.1.316 completed a same-agent question, scoped edit, authenticated replies and browser reload. It uses the explicit --allow-windows-claude-all-access opt-in. That disables Deno's sandbox and grants broad process, FFI, system, network and filesystem authority. Restricted defaults remain unchanged; an error never authorizes escalation.

Native macOS ARM64 runtime/browser checks used synthetic agent operations; the Mac real-agent route is unverified. A cached Linux Codex route was checked separately, not as native Windows/Mac proof. Fresh installation, interrupted recovery, generic resend/deduplication, Intel Macs, Windows ARM64 and other browsers remain unverified. Check the connection in your actual app. A page opening is not proof that comments reach the agent. If that connection is unavailable, XO can keep helping in the conversation.
