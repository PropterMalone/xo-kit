Other setups

Skip this unless none of the doors fit.

Claude and ChatGPT have guided desktop routes; use their doors if that's what you have. In another app, you can try chat-only help without installing anything or connecting an account. xo has no file-setup adapter for Google or Polytoken yet; don't assume the guided installation will work.

  • Anthropic (Claude) or OpenAI (ChatGPT) desktop: use door 1 or door 2.
  • Codex CLI, already in a terminal: start useful work in your existing agent session; you do not need to download a desktop app or finish all setup first. Ask it to read the kit's shared Codex guidance and terminal section before any chosen file setup. The desktop folder picker, composer controls and memory settings are not CLI instructions. The kit gives safety and return-check criteria, not a tested CLI installation or device-support promise; exact terminal invocation and shortcuts are not established here. If terminal/browser transfer fails, keep working in the existing conversation or use one compact continuation, not repeated screenshots or a desktop-control translation exercise.
  • Google / Gemini: see Can I try xo in Gemini? below.
  • Z.ai or several providers at once: Polytoken is a terminal app for using several model providers. xo has no tested Polytoken file-setup adapter.
  • Your employer provides the AI: check every applicable employer, client and project policy and the app's actual permissions before connecting work sources. A hard ban means no crossing to a personal AI; a specifically authorized narrower route permits only its approved fields, recipient and provider. Where no institutional restriction applies, the human may choose broader scope. Every route still needs informed source-specific consent and a verified gate before xo reads or exports. Unknown policy means no crossing; keep the work in its approved environment meanwhile. This route is untested in v0.

Can I try xo in Gemini?

Yes. You can try the general instructions with a non-sensitive task in Gemini chat: choose a next step, draft something or ask for a note you can copy into your next conversation. That chat-only use has not been tested in Gemini. It doesn't require another subscription, file setup or connected accounts; your app's existing limits still apply.

Google's own agent route for consumer accounts is the Antigravity CLI and desktop app. Google's transition announcement replaces consumer Gemini CLI access with Antigravity, not a one-for-one replacement; enterprise and API access are different. This is not an instruction to install either app. Having a Google AI plan does not establish xo compatibility or guarantee free access.

xo has no Google file-setup adapter. It has not verified Google's instruction loading, folder protection or Prose delivery. The existing Claude Code and Codex Prose routes do not establish Gemini support. Keep using chat if that's enough; a saved note does not prove a new Gemini conversation will read it.

Changing apps. Keep your project notes and current policy. The supported Claude Code route uses CLAUDE.md; the supported Codex route uses AGENTS.md, with different discovery and protection checks. A selected app may need a small exact reviewed instruction bridge, not a blanket rename or settings import. Full setup and migration are optional; your agent reads the kit's setup guide and full adapter before proposing paths or protected changes. For another app, name it and check its current official instruction-discovery documentation first; no compatibility or permission enforcement is assumed.

Devices. xo v0 starts on a computer (Windows, Mac, or Linux). Phone access to saved notes is being worked out and hasn't been tested as part of this kit. Phone-only setup, Chromebook, and tablet aren't covered yet.
