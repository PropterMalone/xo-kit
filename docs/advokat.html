How it works

Start with anything: an existing résumé, a job posting, a short account of something you did.

XO builds a dossier on you—basically, your story—from whatever materials you give it. Then, it helps you find job listings it thinks might work and helps you apply for jobs by tailoring your application materials to the listing.

As it builds those materials, it'll ask you questions to build out your dossier beyond the corners of any one application's materials. This work persists and plays for you in other future job applications, so even if you never hear back from a prospective employer you've still made progress on your job search.

Install Advokat in XO

Copy this message into your XO conversation:

Install Advokat as a reusable module for XO. Follow the Advokat installation guide at https://raw.githubusercontent.com/PropterMalone/xo-kit/a5033243291ebc1c2ab4c6e83a7cc74208cfe092/kit/flows/install-advokat.md. Reuse my existing XO setup and show me any files and instruction changes before writing them. Give Advokat a private job-search folder and make it available when I return in a fresh conversation. Keep my existing work and permissions. Check that it loads the module and the right saved work without this message before calling it installed.

Once it's installed, ask XO to work on your job search. You won't need to paste this message again.

If XO cannot fetch the installation guide, open it yourself and paste the full text with its source URL into the conversation. XO will use it to identify the files it needs for installation.

Finish an application

  • Read the draft with XO. Correct the facts and change anything you dislike. If you're using Prose, you can do this in Prose.
  • Submit through the employer's application process.
  • Tell XO you've applied and give it any confirmation or follow-up date.

Give feedback

Tell XO what helped, what hurt, and any bright new ideas you might have. Then ask it to “make a tester report” using the report guide. It will turn your feedback and the conversation into a draft you can edit.
